# Contributing to the RealEye.io Community Repository

Thank you for your interest in contributing! This repository holds community resources for the [RealEye.io](https://www.realeye.io) Eye-tracking Platform — including guidelines, a knowledge base, FAQ, and roadmap.

## How to Contribute

### 💬 Join the Discussion

The easiest way to contribute is to participate in [GitHub Discussions](../../discussions):

- Ask or answer questions in the **Q&A** category
- Share ideas in the **Ideas** category
- Engage with announcements and general topics

### 📝 Improve Documentation

We welcome improvements to any of the documentation files in this repository:

1. **Fork** this repository
2. Create a new branch: `git checkout -b improve/my-topic`
3. Make your changes — keep edits focused and factual
4. Open a **Pull Request** with a clear description of what you changed and why

#### What to contribute

- Corrections to factual errors in the FAQ or knowledge base
- New FAQ entries for common questions not yet covered
- Improved explanations or examples in the knowledge base
- Additional getting-started guides or tutorials

### 🐛 Report Bugs or Issues with the Platform

If you have found a bug in the RealEye.io platform itself, please use the [Bug Report issue template](.github/ISSUE_TEMPLATE/bug_report.yml).

### 💡 Suggest Features

Have an idea for improving the platform? Submit it via the [Feature Request issue template](.github/ISSUE_TEMPLATE/feature_request.yml) or start a conversation in [Discussions](../../discussions/categories/ideas).

## Guidelines for Good Contributions

- **Be specific** — vague reports are hard to act on. Include steps to reproduce, expected vs. actual behaviour, and screenshots where helpful.
- **Search first** — check if a similar issue or discussion already exists before opening a new one.
- **Stay on topic** — keep discussions relevant to RealEye.io and eye-tracking research.
- **Be respectful** — follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Style Guide for Documentation

- Write in plain, clear English
- Use sentence case for headings
- Use numbered lists for sequential steps, bullet lists for non-sequential items
- Link to official RealEye.io documentation at [https://www.realeye.io](https://www.realeye.io) where relevant

## Questions?

If you are unsure where to start, open a discussion in the [Q&A category](../../discussions/categories/q-a) and the community or team will be happy to help.
