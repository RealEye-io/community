## 🔎 About RealEye.io

[RealEye.io](https://www.realeye.io) is a webcam-based eye-tracking platform that enables remote user research without specialised hardware. Researchers can run eye-tracking studies on participants using nothing but a standard webcam, making eye-tracking accessible at scale.

**Key capabilities:**
- Remote, browser-based eye-tracking with no hardware required
- Heatmaps, gaze replays, and Areas of Interest (AOI) analysis
- Support for images, websites, videos, and 5-second tests
- Panel integration for recruiting participants globally
